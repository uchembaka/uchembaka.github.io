For a discrete random variable, probability is the height of a bar. For a continuous random variable, probability is the area under a curve between two points, and never the height of the curve at a single point. Both are shown below.

Discrete

Probability mass function · a fair die

Click one or more bars

Here the height of each bar is the probability. Select several bars and, because the outcomes are mutually exclusive, their heights simply add up.

Continuous

Probability density function · the standard normal curve

Drag either handle, or click one and use the arrow keys

The height of the curve is a density, not a probability. Only the area under it between two points is a probability. Shrink the interval and the area, and with it the probability, vanishes: Pr(Y = y) = 0 for any single point y.
